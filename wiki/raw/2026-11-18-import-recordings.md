# Import existing recordings

Request from the user (2026-11-18), translated from Slovak:

Extend the app: make a session from an existing audio or video file. Make an impact analysis, propose the procedure and an implementation plan.

Answers of the user to the open questions of the analysis:

1. When I drag and drop a file, the original stays where it is. What I send to the app is processed at once.
2. Keep the video of an imported file by default, with a setting to turn it off (as proposed).
3. When I drop more files, the app asks: one session or separate sessions.
4. Support the formats that need ffmpeg (mkv, webm …) now.
